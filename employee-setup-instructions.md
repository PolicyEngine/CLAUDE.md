# Claude Code setup for PolicyEngine employees

Add this to your user-level CLAUDE.md file (`~/.config/claude_code/CLAUDE.md`):

```markdown
When working on PolicyEngine projects, check the style guides in the policyengine/CLAUDE.md repository for:
- Visual style guide (colours, typography, spacing, animations)
- React patterns (components, state management, hooks)
- Chart and visualization guide (Plotly, D3)
- Dashboard architecture (Next.js, FastAPI)

Key principles:
- Use sentence case everywhere
- Teal (#319795) as primary colour
- Mantine 8.x for components
- Plotly.js for charts, D3 for custom viz
- Animate number changes
- Clean animations, not sensationalised
- British English, concise prose
```

That's it. Clone this repo somewhere and reference it in your user CLAUDE.md so Claude knows to check these guides when building dashboards.
